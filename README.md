# 月余

一个为 iPhone 设计的完全离线私人记账本。账目保存在当前设备的浏览器中，没有账号、云数据库、统计代码或付费接口。

## 本地运行

```powershell
npm start
```

然后在电脑浏览器打开 <http://localhost:4173>。

## 数据规则

- 工资、收账属于收入。
- 当月还款、当月房租、日常开销、特殊开销属于支出。
- 预计结余 = 预计收入 - 预计支出。
- 实际结余 = 实际收入 - 实际支出。
- 当前余额 = 起始余额 + 全部实际收入 - 全部实际支出。

## iPhone 安装

iPhone 上安装 PWA 需要一个 HTTPS 地址。部署后，用 Safari 打开地址，点击“分享”→“添加到主屏幕”。第一次打开并完成缓存后，日常记账可以断网使用，数据仍只保存在 iPhone 本地。

在确定最终托管方式之前，不要删除浏览器数据。建议每月在“数据”页导出一次 JSON 备份。
